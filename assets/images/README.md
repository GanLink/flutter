# Assets - Images

## Logo
Coloca tu logo del producto aquí con el nombre `logo.png`

La imagen se mostrará en un círculo de 120x120 píxeles.

**Recomendaciones:**
- Formato: PNG con fondo transparente
- Tamaño recomendado: 512x512 píxeles o mayor
- Relación de aspecto: 1:1 (cuadrado)
- La imagen se recortará en forma circular automáticamente
